## 👨‍💻 Sobre Mim

Profissional de dados com forte base em Análise e Business Intelligence, atualmente em transição para a **Engenharia de Dados** e focado na jornada de longo prazo para me tornar um **Cientista de Dados**. Tenho experiência prática na gestão, tratamento e análise de grandes volumes de informações institucionais, como o Censo da Educação Superior.

Minha paixão é atuar nos bastidores: construindo a arquitetura, automatizando fluxos de dados (Pipelines/ETL) e garantindo que a informação chegue limpa e estruturada para a modelagem preditiva e tomada de decisão pelo negócio.

- 🎓 **Formação:** Gestão da Tecnologia da Informação (UNIAENE).
- 🎯 **Foco Atual:** Arquitetura de Dados, Orquestração de Pipelines (ETL/ELT), Bancos de Dados Relacionais e base em Machine Learning.
- 🌍 **Línguas:** Português (Nativo) e Inglês (Profissional).

## 🚀 Portfólio de Projetos

### 📈 Análise de Ações e Mercado Financeiro (PETR4 / ITUB4)
Construção de um painel interativo em Python para análise de flutuações da bolsa de valores (2025). O projeto atua como um mini-pipeline de extração de dados reais via API (`yfinance`), processamento e limpeza com `Pandas` e criação de dashboards financeiros (gráficos de linha e histogramas) com `Matplotlib`.
> 🔗 [Ver Projeto Completo no GitHub](COLE_AQUI_O_LINK_DO_SEU_REPOSITORIO_DE_HOJE)

### 📊 Omnichannel Marketing Analytics
Pipeline de dados completo criado para otimizar os investimentos publicitários de campanhas. Utilização de Python para a orquestração de dados, modelagem em SQL e desenvolvimento de Dashboards estratégicos no Power BI para apoio à tomada de decisão.

### 🛒 Análise de E-commerce (Base Olist)
Limpeza, Análise Exploratória (EDA) e processamento em lote de uma base de dados massiva do mundo real (Olist). Integração de queries avançadas em SQL e scripts Python, resultando em métricas de negócio consolidadas através de relatórios visuais no Power BI.
